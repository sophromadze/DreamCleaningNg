How an order's source is decided

The source is the customer's first visit to the site (kept for 90 days), saved on the order when they book. The first rule that matches wins:

  1. Admin-booked — an admin created the order (Admin Mode, recreate, recurring).
  2. Paid ads — the first visit came from an ad click (Google Ads gclid / gbraid / wbraid, Microsoft Ads msclkid) or a paid campaign link (utm_medium cpc, ppc, paid…).
  3. AI assistant, Email, Social — ChatGPT, Gemini, Claude…; our email links; Facebook, Instagram, TikTok…
  4. Organic search — Google, Bing, DuckDuckGo… with no ad click.
  5. Direct — typed the address or used a bookmark.
  6. Referral — a link on another site (Yelp, a blog, a partner…).
  7. Unknown — nothing was recorded.

Older orders, booked before click ids were recorded, use the channel saved at the time (or filled in later from Google Analytics). Orders from before any of that existed show as Unknown.
